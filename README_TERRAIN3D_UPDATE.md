# Terrain3D integration

What's in this folder (drop these into your actual project, merging/overwriting):

- `addons/terrain_3d/` — the whole addon (copy this folder into your project's `addons/` directory, alongside your existing `addons/sky_3d/`).
- `world/world_generator.gd` — replaces your existing file. The terrain-building code now creates a `Terrain3D` node and feeds it a heightmap baked from the same `get_height()` function (same seed, same noise, same lake/tower/vegetation logic — nothing else in the file changed).
- `project.godot` — same as yours, with one line changed: `terrain_3d` added to `[editor_plugins] enabled`. If you've changed other project settings since exporting this project, just add `"res://addons/terrain_3d/plugin.cfg"` to your existing `enabled` array instead of overwriting the whole file.

## Steps

1. Copy `addons/terrain_3d/` into your project's `addons/` folder.
2. Replace `world/world_generator.gd` with the version here.
3. Merge the `[editor_plugins]` line from `project.godot` into your project's `project.godot` (or just overwrite it if you haven't changed anything else).
4. Open the project in Godot. Godot should prompt you to enable/reload the Terrain3D plugin — say yes (or enable it manually under Project Settings > Plugins if it doesn't prompt).
5. Run the `world.tscn` scene (or press F5). `WorldGenerator._ready()` builds the Terrain3D node at startup exactly like it used to build the old mesh.

## What changed visually / functionally

- The ground is now a real Terrain3D clipmap terrain instead of one fixed-resolution ArrayMesh: proper LOD, and it'll hold up much better if you ever make `terrain_size` bigger.
- Texturing: two procedurally-speckled swatches (grass, rock) are generated in code and wired into Terrain3D's autoshader, which blends them by slope — same "flat ground = grass, steep = rock" idea as the old per-vertex coloring, just as real textures.
- Collision is now generated by Terrain3D itself (`collision_mode = FULL_GAME`, since the map is small), replacing the old manual `HeightMapShape3D`.
- Not carried over: the old sand band right at the waterline. Terrain3D's autoshader only blends 2 textures by slope, so a height-based 3rd texture isn't automatic. A "Sand" texture (id 2) is registered and ready to go — if you want it back, select the Terrain3D node in the editor, open the Terrain3D dock at the bottom, and paint texture id 2 along the shoreline with the Spray Texture tool. Two minutes of painting and it's done.
- Everything else (lake plane, watchtower, trees, rocks, fireflies, the indoor room) is untouched — they all still read ground height from the same `get_height()` function, so nothing shifted.
